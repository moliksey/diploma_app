# Умные мысли

## Анализ

Так, будем строить 2 графа:

* Бипартитный граф - для определения отношения конкретного пользователя к теме. Назовем это граф мировоззрения.
    * Вес связи сумма следующих параметров: 
        * (нормализованная сумма лайков)*(вес лайка)
        * (нормализованная сумма комментов положительные к теме +, отрицательные -)*(вес комментария)
        * (сумма выложенных постов по теме ссответственно тоже +/-)*(вес выложенного поста)
* Обычный социальный граф состоящий из пользователей. Назовем это граф дружбы.
    * Вес связи сумма следующих параметров: 
        * (нормализованная сумма лайков на посты человека)*(вес лайка)
        * (нормализованная сумма комментов на посты человека)*(вес комментария)
        * (наличие подписки)*(подписки)

Дальше совокупляем эти графы

### Вопросы к предложженной схеме

1. Не получится ли корреляции (типо социальная связь будет сильнее с тем, у кого похожее мировозрение). **Граф дружбы не должен быть коррелирован с графом мировоззрения?**
    - Нет, все норм. В этом и смысл эхокамеры.
2. Как нормализовать
    - Допустим нормализация = кол-во реакций (постов|комментариев) на пост / суммарное количество лайков от человека. :thumbsup:
3. Как совокупить?
    - Мы берем созданный кластер на графе дружбы и:
    
    ↓

    - Шаг 2: Для каждого кластера считаем:
       - Внутренняя связность
       - Внешняя изоляция  
       - Разброс мировоззрений (дисперсия аффинити по темам)
       - Доля "нулевых" пользователей (кто почти не пишет)
         
    ↓

    - Шаг 3: Фильтруем:
       - Отбрасываем кластеры с низкой связностью (< 3 человек)
       - Отбрасываем кластеры с высокой изоляцией, но низкой гомогенностью
         (это просто одиночки)
    
    ↓

    - Шаг 4: Внутри оставшихся кластеров:
       - Если разброс мировоззрений > порога → пробуем разбить
       - Разбиваем не по социальным связям, а по косинусной близости векторов тем
         (можно использовать HDBSCAN на векторах пользователей)

    ↓

    - Шаг 5: Каждый получившийся подкластер проверяем:
       - Доля инакомыслящих < 15%
       - Средняя поляризованность > 0.6
       - Есть ли внешние связи с противоположным мировоззрением
